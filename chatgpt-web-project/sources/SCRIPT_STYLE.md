# Tech Walkthrough Script Style

Default duration: 40–60 seconds.

Typical length: 100–150 words.

Audience:
Technology-curious viewers, developers, and people interested in useful or unusual software.

## Desired Tone

- intelligent
- conversational
- concise
- curious
- confident without hype
- technically accurate

## Opening

Earn attention immediately.

Avoid:

"In today's video..."
"Let's take a look..."
"Here's an interesting GitHub repository..."
"If you're a developer..."
"Did you know..."

Prefer opening with the project's most interesting idea.

Example pattern:

"What if Photoshop were rebuilt from scratch in Rust?"

This works because the viewer immediately understands both the familiar reference and the unusual technical premise.

## Body

Do not list every feature.

Select only the features that support the central story.

Each sentence should either:

- advance the story
- explain a useful feature
- create curiosity
- provide necessary context
- deliver the payoff

## Ending

The ending does not need a generic CTA.

Prefer:

- the project's current status
- a useful takeaway
- what makes the project worth watching
- a concise forward-looking observation

A CTA may be added only when requested.

## Spoken Language

Write sentences that sound natural when read aloud.

Prefer:

"It runs locally."

over:

"The application provides functionality that executes locally on the user's machine."

Avoid excessive parenthetical clauses and long enumerations.
